# cursor-canvas-share

Share a local Cursor `.canvas.tsx` or Markdown file as a short link.

```bash
npx --yes github:brian-mwirigi/canvas-share review.canvas.tsx
# or after npm publish: npx cursor-canvas-share review.canvas.tsx
# https://brianmunene.me/canvas/a8k2m9qx
```

Viewer: [brianmunene.me/canvas](https://brianmunene.me/canvas)  
Demo: [brianmunene.me/canvas/demo](https://brianmunene.me/canvas/demo)
