# cursor-canvas-share

Share a local Cursor `.canvas.tsx`, Markdown, HTML artifact, or JSON file as a short link.

```bash
npx --yes github:brian-mwirigi/canvas-share review.canvas.tsx
npx --yes github:brian-mwirigi/canvas-share notes.md
npx --yes github:brian-mwirigi/canvas-share artifact.html
# https://brianmunene.me/canvas/a8k2m9qx
```

Viewer: [brianmunene.me/canvas](https://brianmunene.me/canvas)  
Demos: [brianmunene.me/canvas/demo](https://brianmunene.me/canvas/demo)
